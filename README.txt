Omid Travel Iran - نسخة جاهزة لـ GitHub Pages

الصفحات:
- index.html: الصفحة الرئيسية (السياحة + السياحة العلاجية + 4 خدمات)
- tourism.html: صفحة الوجهات والمدن
- medical.html: صفحة السياحة العلاجية
- destinations/*.html: صفحات طهران، جيلان، كلاردشت، شيراز، أصفهان، مشهد، تبريز

الرفع على GitHub Pages:
1. فك ضغط الملف.
2. ارفع كل الملفات والمجلدات إلى مستودع GitHub.
3. من Settings > Pages اختر Deploy from branch ثم main و /root.
4. احفظ وانتظر نشر الموقع.

ملاحظة: تصاویر سایت از تصاویر وب خارجی استفاده می‌کنند تا بدون سنگین شدن ZIP نمایش داده شوند.
